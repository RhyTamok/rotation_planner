# Rotation Lab (a fork of XIV in the Shell)

This repository is an independently maintained fork of
[XIV in the Shell](https://github.com/xivintheshell/xivintheshell) (MIT License). It adds the
**Rotation Lab**, a page for planning and comparing FFXIV Viper rotations with deterministic expected
damage. Damage formulas follow [xivgear](https://github.com/xiv-gear-planner/gear-planner). The fork
is not affiliated with either project; please do not report its bugs to them.

Run it with `npm install` and `npm run start`, then open http://localhost:3000/rotation-lab.html.
The original app stays available at http://localhost:3000/. Project notes are in `docs/`.
